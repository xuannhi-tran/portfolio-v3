## What I built

- A full-stack platform with student applications, saved roles, application tracking and **personalised match scores**, plus employer tools for managing job postings and applicants.
- Deployed on **AWS EC2 behind Nginx** with HTTPS and a custom domain.
- Migrated from SQLite to **PostgreSQL** with a least-privilege database role.
- **Real-time notifications** using Django Channels, WebSockets and Redis.
- Security controls: PDF upload validation, role-based access control and firewall rules (Security Groups, UFW).

## Team

I **led a team of 5 student engineers**: I ran weekly meetings, set up the Git workflow, and did code reviews and pull request testing.
